The worksheets create an opening for providers to bring **concrete, testable solutions** — not only arguments for or against cuts. Those openings map almost directly onto the following themes:

| Commission pressure | Provider response theme |
| --- | --- |
| <Term id="cfc">CFC</Term> <Term id="utilization">utilization</Term> / <Term id="paid-family-caregiving">paid family care</Term> growth | Proportionate requirements; quality provider infrastructure |
| Peer/support oversight gaps | <Term id="program-integrity">Program integrity</Term>; real-time technology flags |
| Forecasting failure | Better data + operational input before design changes |
| Admin vs. direct care dollars | <Term id="administrative-sustainability">Administrative sustainability</Term>; simplify duplication |
| Cut cautions / <Term id="cost-shifting">cost shifting</Term> | Don’t cut services first — fix admin and oversight |

## Questions the briefing raises for HCBS stakeholders

1. Where can Colorado improve oversight and utilization controls **without** reducing appropriate <Term id="hcbs">HCBS</Term> access?
2. Are training, credentialing, documentation, and compliance requirements **proportionate** across comparable non-skilled services?
3. Can technology reduce duplicative admin work, strengthen real-time monitoring, and flag unusual utilization earlier?
4. Can Colorado distinguish dollars reaching **direct care** from dollars absorbed by admin layers, contracts, and <Term id="case-management">case management</Term>?
5. Where did original CFC forecasting assumptions fail, and what data should guide future expansions or reductions?
