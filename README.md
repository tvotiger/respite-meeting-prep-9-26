# Sept 17 Commission briefing

Fumadocs site for the Colorado Commission on Medicaid Sept 17, 2026 worksheet highlights.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Pushes to `main` build a static export and publish the `gh-pages` branch.

In the repo **Settings → Pages**:

1. **Source:** Deploy from a branch
2. **Branch:** `gh-pages` / `/` (root) — not `/docs`
3. Save
